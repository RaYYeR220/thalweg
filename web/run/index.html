    How to read it

    1. system steps always run first: probe, load, camera check, stabilize, orthorectify, diagnose.
    2. Then a brain proposes each call with a reason: the deterministic autopilot or an LLM.
    3. A policy gate written in code checks every call. A denial goes back to the brain, which must fix the problem or escalate.
    4. No tool can issue a flood warning. Only a person can sign one, on the review page.
